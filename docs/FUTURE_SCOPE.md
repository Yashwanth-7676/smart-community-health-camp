# Future Scope

## Next major improvements
1. Replace browser-only localStorage with a real authenticated backend.
2. Add role-based server-side authorization and secure database models.
3. Support multi-device sync and cloud-backed records.
4. Extend the reporting module into deeper analytics and export options.
5. Add real patient reminders using SMS or WhatsApp workflows.
6. Integrate IoT or scan-based devices for queue and intake support.
7. Improve mobile-first UX and accessibility testing across devices.

## What stays out of scope for Version 1
- Real medical diagnosis support
- Production-grade compliance or legal certification
- Public healthcare deployment
- Real payment, insurance, or sensitive record handling

## Recommendation
These features should be treated as future technical enhancements after the current demo workflow is stable and accepted by the academic evaluator.
